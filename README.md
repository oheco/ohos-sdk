# ohos-sdk

本仓库用于分发来自开源鸿蒙（OpenHarmony）的工具链，压缩包请前往 [Releases](https://github.com/oheco/ohos-sdk/releases) 下载。

工具链源码请前往 [OpenHarmony 官方仓库](https://gitcode.com/openharmony) 获取。
